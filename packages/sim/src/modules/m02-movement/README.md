# M02 移動

**責任：** 依移動意圖和速度移動實體，處理與牆的碰撞。

| 項目 | 內容 |
|---|---|
| 讀 | `MoveIntent`、`Speed`、`Collider` |
| 寫 | `Position` |
| 資源 | `map` |
| 系統 | `movement` |

## 規則
- 先走 X 軸再走 Y 軸，貼牆斜走時會沿牆滑動。
- 單次位移必須小於一格，否則會丟錯（不悄悄穿牆）。速度上限和碰撞箱大小由內容檢查把關。
- `sanitizeIntent`：輸入夾在 [-1, 1]，斜向正規化（斜走不會比直走快），NaN／無限大當成 0。

## 演進
- v1（I0）：八方向移動與碰撞
- v2：閃避翻滾
- v3：地形效果（減速、霧）
