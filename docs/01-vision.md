# 01｜願景與設計原則（v0.2）

## 1. 一句話

> 某年秋天，一所座落在台地上的警察大學，迎來了世界和蟲界的交界。
> 你不知道自己覺醒了什麼能力，只知道得先撐過今晚。

- **類型：** 像素風 2D 俯視角的開放式末日生存，加上知識鎖探索
- **人數：** 1–4 人線上合作
- **一局：** MVP 是 3 個遊戲日，約 30–40 分鐘；完整版是 7 個遊戲日

## 2. 舞台

- 舞台是虛構的「**霧嶺警察大學**」（暫定名稱）。
- 地圖配置和住校生活的氛圍，參考你熟悉的真實校園；名稱和細節一律虛構（D-002）。
- 角色是在這所學校讀書的學生。身分只是背景，不限制玩法（D-005）。

## 3. 設計支柱

1. **未知的自己：** 能力沒有說明書，理解能力就是變強的方式。
2. **每局都是平行時空：** 同一座校園，每一局的交界時刻、天氣、裂隙、群心性格、覺醒名單都不一樣。
3. **有邏輯的壓力：** 難度升高一定有世界觀上的理由，而且往多個方向成長，不是單純的數值膨脹。
4. **代價與取捨：** 力量都有代價。代價可以被理解、被管理，甚至被利用。
5. **一起活下去：** 合作有自然的分工，倒下的人有機會被救回來。

## 4. 核心循環

| 時間尺度 | 玩家在做什麼 |
|---|---|
| 秒 | 移動、閃避、攻擊、撿東西、觸發異能徵兆 |
| 分鐘 | 出發探索一棟建築 → 救人或找物資 → 收集線索 → 回到安全點整理推理板 |
| 一天 | 白天探索、晚上守夜。一天結束時集合點名：存檔、清點生者、蟲族演化（I6 起） |
| 跨局 | 認識更多異能、兵種、事件和真相（擴充池） |

## 5. 世界觀（精簡版）

- **交界：** 地球和「群巢位面」（蟲界）相撞，在接觸點撕開裂隙。
- **交融波：** 交界瞬間擴散出去的震盪。
  - 約半數人類覺醒，得到無法用科學解釋的異能。
  - 部分動物、植物、物品出現異化。
- **群心：** 蟲族的分散式意識，會觀察人類並演化。
- **外部世界：** 透過廣播和手機推播，逐步揭露政府和軍方的反應。
- **真相：** 分成好幾層，分散在多局之間慢慢揭露。內容放在擴充池，不在 MVP 範圍內。

## 6. 土地公的呈現原則

**目標：** 土地公在遊戲裡是「守護這片土地的存在」，玩家感受到的是安心和敬意。

1. **不實體化，不戰鬥。** 土地公不會以角色的樣子現身戰鬥，不會成為 Boss，也不會被攻擊。
2. **廟是聖域。** 蟲族無法靠近。廟裡不能拔出武器，也不能被任何人破壞。
3. **擲筊遵循民俗的本意。**
   - 每天只能誠心請示一次，要先上香，並把問題說清楚。
   - 神明不會答錯。問題問得模糊時會給笑筊，請你想清楚再問。
4. **供奉是心意，不是交易。** 上香是請示的禮節，不能拿來換數值獎勵。庇佑會用溫和的方式出現，例如心神安定。
5. **平安符是守廟老伯贈與的。** 它不是戰鬥掉落物，也不能大量取得。
6. **守廟老伯是一位溫和的長者。** 他是誰，故事不說破，也不拿來開玩笑。
7. **用語恭敬。** 例如稱號「受土地公庇佑的人」。不使用「常客」「乾孫」這類輕佻的說法，也不碰香油錢之類的題材。
8. **美術莊重。** 夜裡，廟的香火是整座校園最溫暖的光。

> 照這些原則，土地公在遊戲中是守護者的形象。如果你希望更保守，也可以只保留「廟是聖域」，拿掉擲筊互動。只要改一個設定檔就能切換。

## 7. 系統層與主題層分開

- **系統層**是通用的玩法。例如：「一天結束的檢查點」、「安全區」、「淘汰處理」。
- **主題層**是這款遊戲的外觀和用語。例如：檢查點叫「晚點名」、安全區是「土地公廟」、地圖是「霧嶺警察大學」。
- 主題全部放在 `content/theme/` 裡，包括名稱、文字和地圖。系統程式不寫死任何主題內容。
- **好處：**
  - 換校名、改用語、甚至換整個舞台，都不用動到程式。
  - 校園只會是背景，不會反過來綁住玩法。

## 8. 這款遊戲「不是」什麼

- 不是警察模擬器
- 不是塔防遊戲：可以築路障，但重點是移動、探索和抉擇
- 不是 PvP：至少 MVP 不是
- 不靠刷數值撐重玩價值：重玩價值來自未知和變化
