# I0「地基」本輪說明

> 這一輪的核心問題：**骨架穩不穩？**

## 這一輪做了什麼

你現在可以在瀏覽器裡，用 WASD 或方向鍵，操控一位學生在一張測試版校園地圖上走動。畫面本身很簡單，重點是底下的骨架：

| 項目 | 內容 |
|---|---|
| 邏輯層 | 世界、元件、系統排程、固定 Tick（每秒 20 次）、命名亂數流、事件紀錄、存檔／讀檔、狀態雜湊 |
| 系統合約 | 系統必須宣告讀寫哪些元件、發哪些事件；偷偷越界會直接報錯並指出是誰 |
| 模組 | 地圖（M01）、移動（M02）、玩家加入離開 |
| 重播 | 同一個種子加同一串操作，保證得到完全相同的結果；可以從除錯面板匯出重播檔 |
| 除錯面板 | 按 `` ` `` 鍵開關：暫停、逐格、×4、單獨關系統、看角色資料與事件、匯出重播 |
| 品質把關 | 39 個自動測試、5 個瀏覽器測試、1 份黃金重播、分層規則檢查、內容格式檢查、CI |
| 預留 | 畫面和模擬之間隔了一層「連線階段」，I1 做連線時畫面不用改 |

## 怎麼在你的電腦上跑起來

**只需要做一次：**

1. 安裝 **Node.js**（22 或更新的 LTS 版）：https://nodejs.org
2. 安裝 **Git**：https://git-scm.com
3. 打開終端機（Windows 用 PowerShell，Mac 用「終端機」），輸入：

```
git clone https://github.com/York260/CPU-surviver.git
cd CPU-surviver
git checkout claude/hopeful-cray-m0plb0
npm install
```

**之後每次要玩：**

```
npm run dev
```

終端機會顯示一個網址（通常是 `http://localhost:5173`），用瀏覽器打開就可以了。

**其他有用的指令：**

| 指令 | 用途 |
|---|---|
| `npm run check` | 一次跑完所有檢查（約 10 秒） |
| `npm run test:e2e` | 在真的瀏覽器裡跑冒煙測試 |
| `npm run build` | 打包成可以放到網路上的版本（I1 會用到） |

網址後面可以加參數：`?seed=abc&name=小明`，換種子和角色名字。

## 請你試玩這幾件事

1. **能跑起來嗎？** 照上面的步驟，過程中有沒有卡住？卡在哪一步？
2. **走起來的手感：** 速度快慢、撞牆會不會卡住、斜走順不順？（這些數字在 `content/tuning/players.json`，改完存檔就能試。）
3. **按 `` ` `` 開除錯面板：** 看得懂每一項嗎？試試「暫停」、「逐格」和關掉「movement」。
4. **地圖：** 這是我依照參考資料隨手配的灰盒，**你覺得哪裡和你熟悉的校園差很多？** 可以用文字描述，或隨手畫張草圖拍照給我。
5. **畫面：** 字看得清楚嗎？小人太小還是太大？

**請回報：** 跑起來的截圖，加上試玩回饋模板（見 03 迭代計畫第 6 節）。

## 這一輪驗證了什麼（以及沒驗證什麼）

**已經驗證：**
- 自動測試全數通過，包括：撞牆不會穿牆、貼牆斜走會滑動、讀檔後繼續玩的結果和一路玩下來完全相同、同一個 Tick 裡指令順序不影響結果、事件延遲一個 Tick。
- 黃金重播：四位玩家走 600 個 Tick，最終狀態雜湊固定。重構程式碼後，雜湊沒有變，證明行為沒被動到。
- 故意寫了違反分層的程式碼，檢查規則確實擋得住（跨模組偷看內部、sim 裡用 `Math.random`、客戶端伸手進 sim 內部）。
- 故意把內容檔改壞，檢查會指出是哪個欄位。
- 在無頭 Chromium 裡跑過真實畫面：按鍵會動、放開會停、除錯面板可以暫停和匯出。

**還沒驗證：**
- **你的電腦。** 我只在雲端的環境測過，沒有在真實顯示卡、手機或你的瀏覽器上看過。
- **多人連線。** 這是 I1 的事。
- **長時間遊玩。** 目前只跑過短時間的測試。
- **手感。** 速度和碰撞箱的數字是我暫定的，需要你實際試。

## 這一輪過程中發現並修好的問題

1. 撞牆時角色會卡死不動，因為「貼齊牆面」的邊界寫反了。單元測試抓到。
2. 除錯面板的系統開關沒作用，因為點擊時整個面板重畫，勾選框被換掉。瀏覽器測試抓到。
3. 中文名字和區域標籤糊成一團，因為像素風的縮放設定也套用在文字上。看截圖發現。

## 已知限制

- 美術是程式畫的佔位圖。
- 只有一位本機玩家，沒有蟲、沒有戰鬥。
- 地圖是程式產生的，不是用 Tiled 畫的（I1 會換）。
- 還沒做手機的觸控操作。

## 版本備註

- TypeScript 用 6.0 而不是最新的 7.0，因為 ESLint 的 TypeScript 外掛目前還不支援 7。
- Playwright 固定在 1.56.1，和雲端環境已安裝的瀏覽器版本一致。
- Phaser 用 4.2.1（最新穩定版）。
