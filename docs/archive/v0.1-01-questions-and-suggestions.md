# 01｜三個關鍵問題 × 十項專業建議

> 下面三個問題會直接影響架構、範疇和預算。還沒收到回覆前，整體計畫先照每題的**預設假設**推進；回覆後我會調整計畫，不需要從頭重做。

---

## 三個關鍵問題

### Q1｜產品規格與資源：平台、團隊、時程、引擎？

要確認的是目標平台（PC/Steam、主機、手機、網頁）、預計團隊規模、上市時程、預算等級，以及有沒有指定引擎。

**為什麼重要：** 連線架構（Steam P2P、專用伺服器或網頁）、像素美術的產能、內容量上限，都由這一題決定。

**預設假設：**
- PC（Steam）優先，同時驗證 Steam Deck
- 引擎用 Godot 4，以 GDScript 為主
- 核心團隊 8–12 人
- 約 16 個月進 Early Access
- 買斷制，不販售影響戰力的付費內容

### Q2｜真實性與授權：校名能不能用？內容分級到哪？

要確認的是三件事：會不會洽談中央警察大學的名稱與校景授權；分級目標是普遍級、保護級、輔12、輔15 還是限制級；人類對人類的暴力（例如對趁火打劫者開槍）要不要納入。

**為什麼重要：** 這一題決定能不能用真實校名和建築名、地圖寫實到什麼程度、血腥與寄生畫面的尺度，也決定行銷打法。拿到官方合作的話，它本身就是最大的宣傳點。

**預設假設：**
- 開發期以真實名稱作為內部參考，對外準備虛構校名「國立樹人警察大學」，可以一鍵替換
- 分級目標輔15：蟲族可以肢解；人類不做血腥特寫
- 可以對人類用槍，但會受到「公信力」系統制約

### Q3｜多人與單局的定位：幾人？一局多長？死亡怎麼算？

要確認的是同時連線人數上限（2、4 或 8 人）、單局長度（45 分鐘短局，或可以存檔的數小時長局）、要不要做 PvP 或非對稱模式（一位玩家扮演蟲族群心），以及死亡是不是永久的。

**為什麼重要：** 地圖尺寸、節奏曲線、存檔系統、網路同步成本和平衡方式，都由這一題決定。

**預設假設：**
- 1–4 人線上合作
- 標準局是 7 個遊戲日，約 2–3 小時，每天「晚點名」時可以存檔中斷
- 個人死亡不會結束遊戲：死者轉為「蛻者」繼續玩，全隊覆滅才結算
- 非對稱的「群心模式」排在上市後的更新

## 十項專業建議

### 建議 1｜「交界時刻」隨機化：每一局的起點都不一樣

**做法：** 交界事件可能發生在任何一個日常時段：早點名、上課、射擊課、游泳課、午餐、晚自習、晚點名、熄燈後、週末留校，或九十週年校慶彩排。開局的位置、身上的裝備、穿什麼衣服、周圍的人，全都跟著改變。

- 射擊課時遇上交界：手邊有訓練槍，但人困在射擊館
- 熄燈後遇上交界：所有人穿著運動服擠在宿舍
- 週末留校遇上交界：校園空蕩，物資充足，但幾乎沒有人可以救

**為什麼有效：** 這是「平行時空感」最便宜、也最強的來源。同一張地圖，換一個時刻就是完全不同的開局。

### 建議 2｜「異能語法 × 推理板 × 命名」：讓知識鎖成為核心循環

**做法：** 每個人的異能由五個要素組成：**源**（例如聲音、時間、影）、**觸發**（例如吹哨、受傷、屏息）、**形態**（投射、領域、具現等）、**代價**和**異變**。玩家看不到任何技能說明，只能這樣摸索：

1. 遇到「徵兆」
2. 自動寫進覺醒日誌
3. 在刑事風格的**紅線推理板**上組合假說
4. 實驗驗證
5. 確認源、觸發、形態三要素後，玩家親自**命名**，異能才真正可以控制
6. 五要素全部猜中，揭露**真名**，解鎖終極技

**為什麼有效：** 「理解」就是成長，不是練等。每一次發現，都是玩家自己的頓悟。

**怎麼控管品質：** 用「40 個手工原型 × 程序變體」的混合做法，不做完全隨機組合，避免生出不好玩的能力。

### 建議 3｜群心演化：會學習的敵人

**做法：** 蟲族由一個「群心」統一指揮。每天夜裡，群心會分析玩家當天的戰術，再演化出反制：
- 你常用火，它就長出耐火的濕甲
- 你據守建築，它就派鑽地蠕從地下來
- 你很少殺生，它的好奇心會上升，提早派出會說人話的「譯者」

**為什麼有效：** 難度上升有世界觀上的理由。玩家感受到的是「它在學我」，不是「怪物血量變多了」。這也是重複遊玩時最強的驅動力。

### 建議 4｜七軸壓力 + 導演 AI：讓難度往多個方向成長

**做法：** 難度不是單一數值，而是七條軸各自推進：

| 壓力軸 | 隨時間出現的變化 |
|---|---|
| 生態 | 新兵種出現 |
| 適應 | 群心針對玩家反制 |
| 環境 | 停電、蟲膜蔓延、孢子霧、重力異常 |
| 資源 | 食物腐敗、彈藥見底 |
| 社會 | 恐慌、派系、寄生者混入 |
| 外部 | 隔離令、淨化轟炸倒數 |
| 自身 | 蟲化值、心神、疲勞 |

導演 AI 根據玩家當下的狀態安排高峰和喘息。每一幕主要推進不同的軸，玩家永遠在面對**新的**挑戰，而不只是**更硬**的挑戰。

### 建議 5｜學系就是職業，期別就是階級

**做法：**
- **13 個學系各有一項非超自然的專業技能。** 例如：
  - 鑑識：用魯米諾讓蟲族的費洛蒙路徑現形
  - 交通：用交通錐引導「蟲流」
  - 資管：駭進監視器和校園廣播
  - 法律：朗讀法條，觸發隱藏效果
  - 外事：解讀蟲語
- **期別有實際作用。** 92 期學長姐對 NPC 有指揮力；95 期新生聽到口令會不自覺立正，這個「新生反射」是缺點，但也能拿來利用。

**為什麼有效：** 舞台設在警大，就要讓「警察學生」這個身分本身好玩。四個人組隊時，分工也自然出現。

### 建議 6｜異能波動與「遲發覺醒」：每次使用異能都是風險

**做法：**
- 使用異能會放出「波動」，群心感測得到。越強的招式越容易引來蟲潮。
- 少數局（可以當變數開關）中，玩家一開始還沒覺醒。這段期間你對群心是隱形的，可以潛行，直到在戲劇性的時刻才覺醒。

**為什麼有效：** 異能有了取捨，不再是無腦按鍵。「還沒覺醒」也變成一段有趣的體驗，不是單純的懲罰。

### 建議 7｜公信力：法律與生存之間的取捨

**做法：** 警察身分是武器，也是枷鎖。
- 沒有授權就闖進射擊館彈藥庫、對人類開槍、丟下平民、說謊，都會降低「公信力」
- 依循指揮鏈取得授權、保護平民，會提高公信力
- 公信力影響 NPC 聽不聽你的、撤離名額怎麼排、走到哪個結局，以及結算時的評價

**為什麼有效：** 這是警大題材特有的戲劇張力，扣回校訓「誠」。玩家會面對真正的兩難，而不是一個善惡量表。

### 建議 8｜寄生與信任：輕度社交推理（可選）

**做法：**
- 第 3 幕起，寄生蜂會讓部分 NPC 暗中被寄生。國境系、公安系的玩家可以設檢查哨揪出他們。
- 彩蛋：對可疑對象念出「依警察職權行使法第六條，請出示身分證明」，可能逼擬態蟲現形。
- 朋友局可以開一個選項：其中一名玩家可能被寄生，帶著祕密目標。

**為什麼有效：** 社會軸的壓力有了具體玩法，也為直播和朋友局製造話題。

### 建議 9｜蛻者延續 + 群心模式：多人遊戲不讓任何人坐冷板凳

**做法：**
- 玩家死亡或蟲化值滿了，不會變成觀戰，而是轉為半人半蟲的「蛻者」繼續玩：可以爬牆、聽懂蟲語，但進不了土地公廟。第 4 幕有血清任務可以讓他變回人類。
- 上市後推出非對稱的「群心模式」：一位朋友扮演群心，分配演化點、佈下巢穴、指揮蟲潮。

**為什麼有效：** 合作遊戲最怕有人提早出局。這個設計把「失敗」變成新的玩法。

### 建議 10｜結案報告 + 平行記憶：結算就是分享，進度累積在知識上

**做法：**
- **結算是一份「交界事件結案報告」**，用警察卷宗的形式呈現，內容包括：
  - 評級（對應警察官階）、稱號、成果與教官評語
  - 異能揭曉，包含你從沒發現的那一面
  - 重要事蹟時間軸、成就
  - 倖存者的評價、蟲族的評價
  - 一段開放式結局
  
  報告可以一鍵輸出成分享卡。文字由模板生成；可以選擇接 Claude API 讓文字更生動，離線時回到模板。
- **跨局進度是「平行記憶」，不是數值成長：** 檔案室圖鑑、五層真相拼圖、每日共用種子。

**為什麼有效：** 一場兩小時的冒險，最後濃縮成一張可以炫耀、可以比較的「案件報告」。累積的是知識，不是數值，所以每一局都保有未知感。

- **林口霧：** 霧中的潛行與恐怖
