## 1. 設計支柱

1. **未知的自己。** 你的能力沒有說明書。理解能力就是變強的方式。
2. **每一局都是平行時空。** 同一座校園，不同的時刻、天氣、裂隙、群心性格、覺醒名單。
3. **有邏輯的壓力。** 難度升高一定有世界觀上的理由，而且同時往多個方向成長，不是線性的數值膨脹。
4. **警察的身分既是武器也是枷鎖。** 學系、期別、授權、公信力都是玩法。
5. **一起活下去。** 合作有自然分工，失敗也能繼續玩，救人的價值要讓玩家感受得到。

## 2. 世界觀

### 2.1 交界事件（The Convergence）

地球所在的位面和「群巢位面」（蟲界）像兩顆肥皂泡一樣互相擠壓。接觸點撕開了**裂隙**，接觸當下擴散出去的震盪，叫做**交融波**。

### 2.2 交融波帶來的影響

| 對象 | 影響 | 舉例 |
|---|---|---|
| 人類 | 約半數人**覺醒**，覺醒的是無法用科學解釋的異能。覺不覺醒和善惡、體能都沒有關係 | 你的室友、教官、餐廳阿姨都可能覺醒 |
| 動物 | 部分動物**異化**。有的成為盟友，有的變得危險 | 校犬「黑輪」聽得懂人話；鴿群繞著裂隙飛；白鼻心變得具攻擊性 |
| 植物 | 出現「界生植物」 | 發光苔可以當照明（但會引來蛾）；捕蟲藤會吃蟲族，是天然的防線 |
| 物品 | 部分物品變成**共鳴物**，帶有隱藏特性 | 警哨吹了能震暈斥候；博物館的古董警刀會發光 |
| 物理 | 裂隙附近出現異象 | 低重力、時間錯位、聲音延遲、雙月之夜 |

### 2.3 蟲界與群心

- **群心**（Hive Mind）是一個分散式的意識，透過各地的**母巢節點**指揮整個族群。
- 蟲族溝通靠**費洛蒙**和**振動**。牠們感知世界有五個管道：異能波動、光、聲音、體熱、費洛蒙。不同兵種偏重的管道不同，這是潛行玩法的基礎。
- 蟲族不只是侵略者。牠們的位面正在坍縮，這是一場遷徙（真相第二層）。

### 2.4 外部世界（隨種子變化）

外部局勢用收音機、手機推播和校園廣播逐步揭露：

| 遊戲日 | 外部局勢 |
|---|---|
| D1 | 通訊斷斷續續，全國陷入混亂 |
| D2 | 政府宣布緊急狀態，第一次空投 |
| D3 | 國軍在林口交流道建立防線 |
| D4 | 承諾救援，同時開始徵用覺醒者 |
| D5 | 隔離令 |
| D6 | 淨化轟炸倒數 |
| D7 | 決定命運的窗口 |

每一局的外部局勢會隨機偏向「快速救援」、「遲緩」或「放棄」三種走向之一。

### 2.5 分層真相（分散在很多局裡揭露）

| 層級 | 真相 | 揭露方式 |
|---|---|---|
| L1 | 蟲族入侵 | 第一局就知道 |
| L2 | 蟲界正在坍縮，蟲族是在遷徙 | 譯者對話、群心評價累積 |
| L3 | 交界不是第一次。九十年前，學校留下過一份封存的「甲種異常事件第 001 號」檔案 | 博物館、時光膠囊、公安系檔案 |
| L4 | 交融波挑選覺醒者的規則和「執念與記憶」有關 | 異能圖鑑收集達一定數量 |
| L5 | 土地公廟是「地脈錨點」，掃地的福伯其實是…… | 隱藏結局「地祇之守」 |

> L3 的「九十年前」純屬虛構，不連結任何真實歷史事件或人物。

## 4. 玩家角色

### 4.1 角色建立

- 外觀、姓名、**學系**（13 選 1）、**期別**（92 到 95 期）、**背景特質**（2 個）。
- 背景特質舉例：游泳校隊、射擊隊、柔道隊、夜貓子、家裡開宮廟、重考三年、宿舍長、吉他社、熱舞社、怕蟲（有隱藏的好處）。
- **異能不能選。** 異能由世界種子產生，背景特質只會**微幅**影響機率，例如游泳校隊稍微比較容易抽到和「水」有關的源。

### 4.2 能力值

| 能力值 | 說明 |
|---|---|
| 生命 | 另有傷勢狀態：割傷、骨折、酸蝕、寄生卵 |
| 體力 | 奔跑、閃避、近戰都會消耗 |
| 飢餓、口渴 | 停電後，食物會開始腐敗 |
| 疲勞 | 熬夜會讓瞄準和反應變差 |
| 心神（紀律） | 降低會恐慌、出現幻聽；警大訓練帶來額外抗性 |
| 蟲化值 | 見 5.7 |

### 4.3 學系專長（非超自然）

| 學系 | 專長 | 效果 | 招牌時刻 |
|---|---|---|---|
| 行政警察 | 指揮 | 口令（集合、掩護、撤退、肅靜）效果更好，NPC 士氣恢復更快 | 「全體注意！」 |
| 外事警察 | 語言天賦 | 蟲語解讀速度 ×2，能和外籍學員溝通 | 「協議」結局的關鍵人物 |
| 刑事警察 | 偵查 | 線索會亮起；推理板多一格提示 | 紅線推理板 |
| 公共安全 | 反滲透 | 辨識寄生者；整合情報後，地圖上會出現巢穴的推測位置 | 揪出內鬼 |
| 犯罪防治 | 心理與矯正 | 安撫恐慌、審訊；可以**活捉**並收容蟲族（研究、馴化） | 「矯正」一隻刃螳 |
| 消防 | 救災 | 空氣呼吸器用得更久、會破門、能在火場和孢子霧裡行動 | 水線封鎖蟲潮 |
| 交通 | 管制 | 能開校內車輛；用交通錐和路障引導**蟲流** | 「蟲流管制」 |
| 資訊管理 | 資訊戰 | 駭入監視器、門禁、廣播；操作無人機 | 用校園廣播引走蟲潮 |
| 鑑識科學 | 跡證分析 | 用魯米諾顯現費洛蒙路徑；分析蟲體弱點；鑑定共鳴物 | 追蹤到母巢 |
| 國境警察 | 查驗 | 設立檢查哨，降低寄生者混進來的機率；查驗證件 | 「請出示證件」 |
| 水上警察 | 水域 | 會游泳潛水；能探索泳池裂隙、救溺水的人 | 潛入水之裂隙 |
| 法律 | 法理 | 談判、調解衝突；**朗讀法條**能觸發隱藏效果 | 警職法第六條 |
| 行政管理 | 後勤 | 物資管理效率更好、據點建設成本降低、能排班 | 「末日排班表」 |

### 4.4 期別與階級

- **92 期（學長姐）：** NPC 服從度提高，可以使用「整隊」指令，但責任也更重：學弟妹死亡時，心神下降得更多。
- **95 期（新生）：** 剛結束新生預備教育，體力加成。有「新生反射」：聽到口令會立正 0.5 秒。這是弱點，但被寄生的「教官」也會被自己的口令卡住，所以也能利用；滿足一定條件後可以克服。
- 指揮鏈：最高階的倖存者掌握「授權」。教官、長官死亡時，指揮權往下傳，有可能傳到你身上。

## 5. 異能系統「未知的自己」

### 5.1 原則

不給技能樹、不給名字、不給說明。你只能**發現**。

### 5.2 異能語法

| 要素 | 說明 | 選項池（例） |
|---|---|---|
| **源** | 能力的本質 | 動能、熱、寒、光、聲、電磁、重力、時間、空間、生命、腐朽、影、心念、記憶、機率、蟲（共鳴） |
| **觸發** | 什麼情況下發動 | 觸碰、凝視、發聲或喊口令、吹哨、屏息、受傷、情緒高張（恐懼、憤怒、悲傷）、靜止三秒、全速奔跑、夜間、雨中或霧中、拿著特定物品（警棍、手銬、哨子、書）、他人瀕死、敲出節奏、說真話、睡眠中 |
| **形態** | 效果怎麼呈現 | 自身強化、投射、領域、標記、具現、轉移、交換、連結 |
| **代價** | 要付出什麼 | 體力、體溫、飢餓、**記憶碎片**（日誌條目會被抹掉）、蟲化值、心神、波動（引來蟲）、和隊友分攤傷害 |
| **異變** | 隱藏特性，0–2 個 | 條件反轉（例如雨中效果相反）、過敏物、共鳴對象、成長型（每救一個人就變強）、失控機率 |

### 5.3 手工原型 × 程序變體

- 1.0 版本有 **40 個手工原型**，另有 6 個隱藏原型。每個原型定義合法的語法組合和效果腳本；程序只負責數值、外觀和異變。
- 這樣做的好處：每個能力都經過設計和測試，同時保有組合帶來的未知感。

**原型範例（括號內是真名，結算時才揭曉）：**

| # | 真名 | 源 → 觸發 → 形態 | 描述 |
|---|---|---|---|
| 1 | 靜默之壁 | 聲 → 吹哨 → 具現 | 哨音凝成一道聲波牆 |
| 2 | 鐵之凝視 | 電磁 → 凝視 → 標記 | 盯著金屬看，它就會被磁化，可以吸附或拋射 |
| 3 | 遲滯 | 時間 → 受傷 → 領域 | 受傷的那一瞬間，周圍時間變慢 |
| 4 | 回溯三秒 | 時間 → 靜止三秒 → 自身 | 回到三秒前的位置；代價是記憶碎片 |
| 5 | 影行 | 影 → 夜間 → 轉移 | 潛進影子裡移動 |
| 6 | 言出法隨 | 心念 → 朗讀法條 → 領域 | 唸出的法條會短暫成為規則，例如「禁止通行」；法律系比較容易抽到 |
| 7 | 共感 | 生命 → 觸碰 → 連結 | 分擔傷勢、治療隊友 |
| 8 | 熱寂 | 熱 → 憤怒 → 投射 | 噴出灼熱；隱藏的反轉面是冰凍 |
| 9 | 蟲語者 | 蟲 → 屏息 → 連結 | 短暫聽懂甚至控制一隻蟲；代價是蟲化值 |
| 10 | 重量錯置 | 重力 → 觸碰 → 交換 | 交換兩個物體的重量 |
| 11 | 霧行者 | 空間 → 霧中 → 自身 | 在霧裡短距離瞬移（林口霧彩蛋） |
| 12 | 點名 | 記憶 → 喊出全名 → 標記 | 喊出某人的全名，就能知道他在哪裡（早點名彩蛋） |
| 13 | 萬物生長 | 生命 → 觸碰植物 → 具現 | 讓界生植物長成屏障 |
| 14 | 偏移 | 機率 → 擲硬幣 → 自身 | 一段時間內好運或厄運 |
| 15 | 腐朽之手 | 腐朽 → 觸碰 → 投射 | 讓甲殼和路障腐蝕 |
| 16 | 光之哨所 | 光 → 靜止 → 領域 | 發光的領域能驅散斥候，但會引來蛾群 |
| 17 | 替身 | 空間 → 受到致命傷 → 交換 | 和附近的物品互換位置 |
| 18 | 鏡像 | 光 → 凝視鏡面 → 具現 | 從鏡子裡召喚出分身 |
| 19 | 誠之鎧 | 心念 → 整局沒說過謊 → 自身 | 減傷（隱藏原型，校訓彩蛋） |
| 20 | 餘燼記憶 | 記憶 → 觸碰物品 → 讀取 | 讀取物品上殘留的記憶，能揭露真相線索 |

### 5.4 發現循環

```
① 徵兆 → ② 異常紀錄 → ③ 推理板 → ④ 實驗 → ⑤ 命名 → ⑥ 深化 → ⑦ 真名
```

1. **徵兆：** 觸發條件成立時，有一定機率不自主發動，並有畫面、聲音、NPC 的反應，例如：「學長，你剛剛眼睛是不是變成金色？」
2. **異常紀錄：** 自動寫進「覺醒日誌」。文字是主觀、模糊的，例如：「09:42 被刃螳劃傷的時候，周圍好像慢了半拍？」
3. **推理板：** 一塊軟木塞板，上面有紅線和便利貼。玩家把線索卡拖到五個欄位，組成假說。
4. **實驗：** 刻意去做觸發條件，結果會強化或推翻假說。**穩定度**介於 0–100%。
5. **命名：** 源、觸發、形態三要素都確認後，玩家輸入一個名字（也可以從建議裡選），異能就變成可以控制的主動技能，有快捷鍵和冷卻時間。之後依使用方式分支成長。
6. **深化：** 找出代價可以減輕反噬；找出異變可以解鎖隱藏潛力。
7. **真名：** 五要素全部正確，揭露真名，解鎖終極技「真名解放」。

**誤解也能用：** 理解不完整時，能力還是能用，只是比較弱、比較不穩定。例如你以為觸發條件是憤怒，其實是心跳加速，所以憤怒有時候有效。

**外部輔助（重要的防挫折設計）：**
- 鑑識大樓的分光儀：揭露源的大類，需要消耗樣本
- 資訊館的波形分析：找出觸發的時間點
- 犯防系的心理晤談：找出情緒類觸發
- 隊友或 NPC 的目擊陳述
- 博物館的古籍
- **土地公廟擲筊：** 對自己的假說問一個是非題。聖筊代表「是」，笑筊代表「再問一次」，陰筊代表「否」。有微小的誤差率；先上供品可以降低誤差。

### 5.5 異能波動與遲發覺醒

- 使用異能會放出**波動**，範圍和強度成正比。群心感測得到，會依波動調派兵力。
- **遲發覺醒**（變數，或 10% 的機率隨機發生）：開局時還沒覺醒，對群心是隱形的，在第 2 或第 3 幕的戲劇性時刻才覺醒。

### 5.6 共鳴連攜（合作）

不同玩家或 NPC 的異能可以產生交互作用，例如：
- 水 × 電：導電陷阱
- 聲 × 空間：遠距聲波
- 光 × 影：互相抵消
- 重力 × 動能：彈射

第一次發現某個組合時，會記錄成「共鳴發現」，結算時也會列出。

### 5.7 蟲化值

- **來源：** 被蟲族所傷、吸進孢子、過度使用異能、某些異能本身的代價。

| 門檻 | 效果 |
|---|---|
| 30 | 聽得懂一點點蟲語 |
| 60 | 外觀開始改變；蟲族攻擊前會猶豫；人類 NPC 不再信任你 |
| 90 | 有失控機率 |
| 100 | 蛻化成「蛻者」（見第 10 章） |

- **治療方式：** 鑑識血清、平安符、在土地公廟靜坐。
- 這是一條風險和報酬並存的軸：蟲化值越高，異能越強。

### 6.4 群心演化（反制軍備競賽）

- 每天晚點名之後，群心進行一次**演化回合**。
- 它會讀取「事件紀錄器」的當日資料：玩家的傷害類型、據點位置、照明使用量、異能種類、殺和捕的比例。
- 然後在**演化點數**的預算內，從演化樹裡挑選反制。
- **摧毀母巢節點會減少它的演化點數**，因此玩家和群心之間存在一層戰略攻防。
- 每次演化都有可觀察的「徵兆」，例如蟲屍上出現新特徵、蟲群行為改變。玩家可以預判，再反制回去。

| 玩家的主要做法 | 群心的反制 | 反制的反制 |
|---|---|---|
| 大量用火 | 濕甲：耐火 | 濕甲導電 → 改用電 |
| 依賴槍械 | 盾甲兵增加、夜襲變多 | 繞到背後、用柔道摔投翻倒牠 |
| 據守建築 | 鑽地蠕、酸甲 | 在地上灑水佈置震動感測、輪換據點 |
| 大量照明 | 趨光蛾群、夜盲變種 | 誘餌燈 |
| 偏重潛行 | 嗅蟲增派、鋪設費洛蒙網 | 用魯米諾找出路網、用辣椒噴霧清除 |
| 頻繁使用異能 | 波動獵手：感知範圍變大 | 改用非異能手段，或製造假波動 |
| 活捉、不殺 | 群心好奇度上升，譯者提早出現 | 走向「協議」結局 |

### 7.3 導演 AI

- 持續計算**緊張度**，依據包括：生命、彈藥、最近的戰鬥、隊伍分散程度、心神。
- 控制「高峰 → 喘息 → 高峰」的波形。喘息時刻包括：
  - 安全屋裡的閒聊
  - 和 NPC 的支線
  - **末日晚點名**
- **末日晚點名（招牌時刻）：** 每晚在據點集合，由最高階的倖存者點名。活著的人答「有」；死去的人名字被唸出後是一片沉默。接著存檔、做當日結算、群心演化回合。
- **人數調整不只是加血量。** 玩家越多，群心越狡猾，同時出現的目標越多，但每隻蟲的血量增加很少。

| 預備教育（簡單） | 徵兆頻率高；推理板有提示 |
| 正期生（標準） | 預設難度 |
| 教官（困難） | 群心演化點數 ×1.5；資源減少 |
| 九十週年（噩夢） | 強制加上 3 個變數，沒有擲筊誤差保護 |
| 自訂 | 每個變數都可以單獨開關 |

### 8.2 劇情主幹：骨架固定，呈現方式隨機

主幹節點依序是：

> 第一聲尖叫 → 第一個覺醒者失控 → 停電 → 第一次末日晚點名 → 國軍廣播 → 寄生者曝光 → 空投 → 隔離令 → 最後一夜 → 決界

每個節點由誰觸發、在哪裡發生、怎麼發生，都會隨機變化。所以每一局都有完整的故事弧線，細節卻每次都不同。

### 8.3 Storylet 範例（每個事件都有前置條件、權重和後果）

**救援**
- **冷凍庫裡的人：** 餐廳阿姨被困在冷凍庫。一開門就會驚動附近的電蝕蟲。

- **博物館參訪團：** 一群來校外教學的國小學生，困在世界警察博物館裡。
- **泳池底的呼吸：** 水上系的學姊潛在泳池底躲蟲，氧氣快用完了。
- **射擊館的鎖：** 管理員受了傷，身上有彈藥庫鑰匙，但他堅持「沒有授權就不能開」。

**物資**
- **空投偏移：** 空投箱落在蟲巢旁邊。

**社交**
- **誰才是學長：** 兩位高年級生爭奪指揮權。

**異象**
- **停在昨天的教室：** 有一間教室的時間停在交界前一分鐘，黑板上寫著明天的考題。
- **倒流的雨**

- **制伏系統：** 可以壓制小型蟲並活捉。犯防系的成功率更高。

### 9.3 製作
- 各建築有不同的工作台：消防大樓的工具、鑑識實驗室的化學、警技館的護具、資訊館的電子零件。
- **配方範例：** 拖把長矛、膠帶護盾、滅火器噴射器、辣椒噴霧手榴彈、魯米諾噴罐、蟲甲護具、費洛蒙誘餌、手機鬧鐘陣列（聲音誘餌）、平安符（土地公廟限定）。

### 9.4 共鳴物
- 受到交融波影響的物品會帶 1–2 個隱藏特性，要鑑定或實際使用才會揭露。這和異能系統是同一種「知識鎖」思路。
- **稀有度：** 普通 → 異化 → 共鳴 → 傳說（博物館）
- **舉例：**

| 共鳴物 | 效果 |
|---|---|
| 學長的筆記 | 推理板提示 +1 |
| 警哨 | 吹響時震暈斥候 |
| 滿分豆腐被 | 傳說級盾牌 |
| 老舊無線電 | 偶爾收到**其他平行時空**的聲音（跨局敘事） |
| 校訓石碎片 | 「誠」的光環 |
| 第一期畢業紀念冊 | 用途未知 |
| 九十週年紀念徽章 | 用途未知 |

### 9.5 據點建設
- **選擇哪裡當據點，就決定了這局的打法：**
  - 射擊館：堡壘型，空間小
  - 大禮堂：容納最多人，但難守
  - 警技館：有泳池當水源，空間大
  - 資訊館：情報型
  - 宿舍：可以休息
- **模組：** 路障、瞭望台、醫護站、廚房、發電機、無線電站、研究台、收容籠、床鋪。
- **NPC 排班：** 哨兵、廚師、醫護、研究、工程。行政管理系的玩家有效率加成。

### 9.6 夥伴與 NPC
- 每局從約 80 名原創 NPC 中抽出 40 名以上登場。
- **每個 NPC 都有：** 性格特質、和玩家的關係（信任與好感）、隱藏的異能（同樣需要被發現）、個人支線、祕密（可能已被寄生，或是迎界會成員）。
- **可以招募成同行夥伴**，每位玩家最多 2–3 名。可以下指令；NPC 死亡是永久的。
- **NPC 會記住你做過的事**，這些記憶就是結算時「倖存者的評價」的素材。
- **固定角色：**

| 角色 | 特色 |
|---|---|
| 嚴厲但護短的區隊長教官 | 第 3 幕可能被寄生，成為「教官」Boss |
| 愛講冷笑話的鑑識教授 | 想要活體樣本 |
| 外籍交換學員 | 協議路線的關鍵 |
| 餐廳的秀琴姨 | 掌管糧食 |
| 駐衛警老張 | 守著正門 |
| 熬夜打電動的資管學長 | 資訊戰幫手 |
| 宮廟出身的學弟 | 懂擲筊 |
| 怕蟲的學妹 | 恐懼本身就是她異能的觸發條件 |
| 土地公廟的掃地老伯「福伯」 | 謎樣人物 |
| 校犬「黑輪」 | 異化後能聽懂人話 |

### 9.7 公信力（警察倫理）

| 會提高公信力 | 會降低公信力 |
|---|---|
| 保護平民 | 搶奪物資 |
| 依指揮鏈取得授權 | 沒有授權就打開彈藥庫 |
| 救人 | 拋下傷者 |
| 誠實 | 說謊 |
| 合乎比例原則地使用武力 | 對人類開槍（視情況判定） |

公信力影響：
- NPC 願不願意聽從
- 撤離時的優先順序
- 國軍的態度
- 能走到哪些結局
- 結算時的評語

## 10. 多人連線

- **1–4 人合作，可以中途加入或退出。** 新加入的玩家以「從其他大樓逃過來的倖存者」身分融入劇情。
- **世界共享、異能各自獨立、據點共享。**
- **通訊：**
  - 可選的近距離語音
  - 遊戲內無線電，有距離和頻道限制
  - 迴聲蟬能**偽造**無線電訊息，所以隊伍要自己約定暗號，這是一層刻意設計的偏執感
- **倒地救援：** 倒地後由隊友扶起，NPC 也能把你拖走。
- **蛻者：** 死亡或蟲化值滿了，就變成半人半蟲繼續玩。
  - 能力：爬牆、感知費洛蒙、和蟲族溝通
  - 限制：進不了土地公廟，人類 NPC 會害怕你
  - 第 4 幕有血清任務，可以讓蛻者變回人類
- **隱藏寄生者**（朋友局才有，預設關閉）：第 3 幕時，可能有一名玩家暗中被寄生，帶著祕密目標。
- **群心模式**（上市後）：1 名玩家扮演群心，用類似簡化 RTS 的方式操作，對抗 1–4 名倖存者。

## 11. 結算：交界事件結案報告

### 11.1 報告結構

報告以警察卷宗的形式呈現：牛皮紙封面、公文格式、印章。

| 區塊 | 內容 |
|---|---|
| 封面 | 案號（就是種子碼）、日期、存活天數、結局類型、參與人員 |
| 一、評級 | S+ 到 F，對應官階：S+ 警監特階、S 警監、A 警正、B 警佐、C 實習警員、D 見習生、F 退訓 |
| 二、稱號 | 一個主稱號、兩個副稱號，依行為標籤和稀有度產生 |
| 三、成果與評語 | 存活天數、救援人數、擊殺與活捉數、擊倒的 Boss、據點等級、異能探索度、公信力，加上一段用教官口吻寫的**教官評語** |
| 四、異能揭曉 | 真名；五要素（已發現的打勾，沒發現的揭曉）；探索度百分比；「你從來不知道……」；使用統計 |
| 五、重要事蹟 | 從事件紀錄器挑出 5–8 個高光時刻，排成時間軸 |
| 六、成就 | 本局解鎖的成就和累積進度 |
| 七、倖存者的評價 | 3–5 位 NPC 的話，依關係值和記憶產生；死者用「遺言」呈現 |
| 八、蟲族的評價 | 「群心紀錄」：用異族的口吻寫出威脅等級、對你戰術的觀察、它怎麼演化、它會不會「記住」你 |
| 九、結局 | 150–250 字的開放式結局，最後留下一個鉤子 |
| 分享卡 | 一張圖，可以分享到社群 |

**評分權重：**

| 項目 | 權重 |
|---|---|
| 存活 | 25% |
| 救援 | 20% |
| 異能探索 | 15% |
| 戰功 | 15% |
| 公信力 | 10% |
| 團隊 | 10% |
| 隱藏加分（彩蛋、共鳴發現） | 5% |

### 11.2 文字生成
- **基本做法：** 模板 + 語法片段（Tracery 風格）+ 事件變數。完全離線也能運作，品質穩定。
- **進階（可選）：** 透過後端代理呼叫 Claude API，根據事件紀錄寫出更有個人色彩的評語和結局。需要設定速率限制和快取；失敗時回到模板。

## 12. 跨局進度：平行記憶

- **原則：** 不做數值成長。跨局累積的是**知識**和**收藏**。
- **檔案室（Codex）：** 蟲族圖鑑、NPC 檔案、真相文件、異能圖鑑（收集已發現的真名，共 40 + 6 個原型）。
- **似曾相識：** 只提供側向的小加成，例如開局多一張線索卡、某個 NPC 好像「認得你」。
- **每日／每週平行時空：** 全服共用種子，各自挑戰並比較評級；種子碼可以分享。
- **老舊無線電：** 偶爾播出**你自己上一局**的片段，例如某一句遺言。這是 Meta 敘事的鉤子。

## 13. 彩蛋清單

1. **早點名答「有」：** 教官唸到你的名字時，在準確的時機按互動鍵，可以獲得增益。
2. **內務櫃：** 物品欄就是你的內務櫃。整理得整齊，教官 NPC 會點頭。
3. **豆腐被：** 傳說級盾牌，只在「內務檢查前夜」事件中取得。
4. **立正：** 95 期新生的「新生反射」；被寄生的教官也會被自己的口令卡住。
5. **擲筊：** 用聖筊、笑筊、陰筊驗證異能假說。
6. **土地公廟：** 守住它直到最後，有機會進入隱藏結局「地祇之守」。
7. **警職法第六條：** 念出來可以逼擬物蟲和寄生者現形。
8. **校訓「誠」：** 整局沒說過謊，才有機會抽到隱藏原型「誠之鎧」。
9. **熄燈號：** 吹與不吹，是秩序和安全之間的取捨。
10. **林口霧：** 霧天時潛行加成，迴聲蟬也更危險。
11. **博物館的各國警帽：** 戴上之後會隨機獲得某種「語言」能力。
12. **九十週年時光膠囊：** 真相第三層的入口。
13. **黑輪：** 餵牠十次，牠會帶你找到隱藏物資。
14. **CPU：** 資管系的玩家駭進群心的訊號後，發現它的運作方式像一顆 CPU。開發團隊的自嘲。
15. **漆彈標記：** 射擊館 1F 的訓練裝備，在末日裡派上用場。
16. **蟲流管制：** 交通系用交通錐引導蟲潮，繞進泳池。
17. **停在昨天的教室：** 抄下黑板上明天的考題。如果有下一局，期中考會考那一題。
18. **鏡中點名：** 第 4 幕午夜十二點，宿舍的鏡子。
19. **秀琴姨的滷肉飯：** 末日裡最高級的心神回復道具。
20. **最後的畢業典禮：** 撥穗的人是誰，取決於誰還活著。

## 14. 美術與音效方向

### 14.1 美術

- **視角與規格：** 3/4 俯視；格子 16×16；角色 16×32；基礎解析度 480×270，整數放大 ×4 到 1080p。
- **用色來說故事：**
  - 日常：溫暖的校園綠、磚紅、夕陽橘
  - 交界：生物光紫和青綠，從裂隙往外「侵蝕」整個色盤
  - 蝕潮：酸綠和深黑
  - 整個色盤會隨著幕次和蟲膜擴張，逐格改變
- **光影：** 2D 動態光源。手電筒的光錐是潛行的核心；林口霧和孢子霧用 Shader 呈現；日夜循環；雙月之夜。
- **蟲族造型：** 以臺灣本土昆蟲為靈感再加以異化，不要 1:1 照抄。剪影要一眼就能辨識兵種。
- **UI：** 公文和卷宗風格（牛皮紙、印章、迴紋針）。推理板用軟木塞板加紅線。地圖做成校區平面圖，上面有手寫註記。

### 14.2 音效

- **音樂：** 晶片音樂混合真實樂器。依緊張度動態疊加聲部。主題動機是**起床號**和**熄燈號**的變奏。
- **群心：** 群心的「合唱」是蟲族的主導動機。越靠近巢穴，和聲越完整。
- **空間音效是核心玩法：** 潛行要聽腳步；迴聲蟬的偽聲要能被細心的玩家分辨出來，例如有極細微的相位異常。
- **環境音：** 林口的風聲、霧中的回聲、遠處國道的車聲。車聲越來越少，暗示外界的變化。

## 16. 技術架構（預設 Godot 4）

| 模組 | 方案 |
|---|---|
| 引擎 | Godot 4 最新穩定版。玩法用 GDScript；如果蟲群效能吃緊，再用 C++ GDExtension 改寫 |
| 連線 | 主機權威的 Listen Server；Steam 用 GodotSteam（P2P 與大廳）；開發期用 ENet 直連；快照 20–30Hz；興趣管理（Interest Management） |
| 蟲群 | Flow Field 尋路加上局部避障（Boids）。遠方的蟲群抽象成「群單位」模擬（AI LOD）。精英怪用 Utility AI 或行為樹 |
| 群心 | 戰略層的 Utility AI，讀取事件紀錄器的資料，產生演化決策 |
| 導演 | 緊張度模型，控制生成預算、事件觸發和喘息時刻 |
| 事件 | Storylet 引擎：前置條件、權重、後果；內容資料驅動（JSON 或 Godot Resource） |
| 異能 | 語法資料 + 效果節點組合（觸發節點 → 效果節點 → 代價節點）；發現進度按玩家分開保存 |
| **事件紀錄器** | **一份資料，三種用途：** 群心演化、結案報告、平衡分析 |
| 存檔 | 晚點名時存快照：種子 + 差異 |
| 工具 | 地圖用 Godot TileMap；自製編輯器：Storylet、異能語法、NPC；除錯面板可以看緊張度曲線和群心思考 |
| 測試 | GUT 單元測試；無頭模擬（機器人自動跑局）做種子驗證和平衡 |
| 文字生成 | 模板引擎；可選的 Claude API 後端代理 |
| 模組支援 | 內容資料化之後，可以提供官方模組工具 |

## 18. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| 知識鎖太難，玩家挫折 | 流失 | 徵兆頻率依難度調整；擲筊、分光儀、隊友觀察等外部輔助；「誤解也能用」；遙測監控發現率 |
| 隨機性破壞平衡 | 出現必死局 | 手工原型、種子驗證器（無頭模擬）、物資最低保證 |
| 蟲群加多人同步的效能 | 卡頓 | 抽象群單位、興趣管理、及早做效能技術驗證 |
| 真實學校授權與形象 | 法律或公關風險 | 雙軌命名、轉譯原則、顧問審閱 |
| 蟲恐懼 | 潛在玩家流失 | 蟲恐懼友善模式 |
| 範疇膨脹 | 延期 | 垂直切片關卡制、內容規模表、每兩週出可玩版本 |
| 社交推理引發朋友間的負面情緒 | 口碑 | 隱藏寄生者預設關閉，限朋友局 |
| AI 文字生成的不穩定 | 內容風險 | 模板優先；生成時加安全過濾；只用在評語和結局 |
