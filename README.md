# 樹人路56號：蟲潮交界（暫定）｜Project CPU-surviver

像素風 2D 俯視角的開放式末日生存遊戲，1–4 人線上合作。故事舞台在中央警察大學（桃園市龜山區樹人路 56 號）。

> 2026 年秋天，警大創校九十週年前夕，世界和蟲界撞在一起。
> 你是警大的學生，不知道自己覺醒了什麼能力，只知道今晚的晚點名，可能是最後一次。

**狀態：** 前期製作。設計提案 v0.1。

## 核心特色

- **未知的自己：** 異能由「異能語法」產生，每一局、每個人都不一樣。要靠徵兆、推理板、實驗和命名，才能找出自己的能力。
- **每一局都是平行時空：** 交界發生的時刻、天氣、裂隙位置、群心性格、覺醒名單全都隨機。
- **會學習的敵人：** 群心每天晚上演化，反制你的戰術。難度沿著七條軸非線性地上升。
- **警察身分就是玩法：** 13 個學系各有專長，期別有階級差異，用槍要有授權，公信力會影響局勢。
- **交界事件結案報告：** 結算時包含評級、稱號、異能揭曉、倖存者的評價、蟲族的評價，以及一段開放式結局。
