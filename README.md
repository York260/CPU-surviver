# 蟲潮交界（暫定）｜Project CPU-surviver

像素風 2D 俯視角的開放式末日生存遊戲，支援 1–4 人線上合作。

> 某年秋天，一所座落在台地上的警察大學，迎來了世界和蟲界的交界。
> 你不知道自己覺醒了什麼能力，只知道得先撐過今晚。

**狀態：** 迭代 I0「地基」完成，等待試玩回饋。目標是 MVP：做出你和朋友能一起玩完整一局的版本（D-001）。
**怎麼跑：** 見 [I0 本輪說明](docs/iterations/I0-handoff.md)。

## 快速開始

```
npm install
npm run dev      # 開發伺服器，用瀏覽器打開顯示的網址
npm run check    # 一次跑完 lint、型別、內容檢查、測試
```

## 專案結構

| 資料夾 | 內容 |
|---|---|
| `packages/sim` | 純邏輯層：不認識畫面和網路，不用隨機數和現實時間 |
| `packages/client` | 瀏覽器端：Phaser 畫面、輸入、除錯面板 |
| `packages/tools` | 重播、內容檢查等工具 |
| `content/` | 資料檔與主題文字（校名、用語都在這裡） |
| `tests/` | 情境測試與黃金重播 |
